HTML Linguagem de Marcação de Hipertexto

Tutoriais para Iniciantes

HTML (Linguagem de Marcação de Hipertexto) é o bloco de construção mais básico da web. Define o significado e a estrutura do conteúdo da web. Outras tecnologias além do HTML geralmente são usadas para descrever a apareência/apresentação (CSS) ou a funcionalidade/comportamento (JavaScript) de uma página da web
